# Sarvadnya Bhatlawande

Pune. I build LLM agents, retrieval systems and backend services, and I try to measure what they actually do rather than trust a demo.

**Working on:** multi-agent LLM pipelines, RAG over real documents, reasoning in small language models, Java/Spring backends.

## Projects

- **[ClearFlow](https://github.com/sarvadnya2030/Clearflow)**: ISO 20022 payment orchestration in Java 21, Spring Boot 3.3, Kafka and Apache Camel, with an MCP observability layer. 41 tests.
- **[HC01](https://github.com/sarvadnya2030/ignisia-mitwpu-hackathon)**: ICU clinical decision support built at Ignisia 2026 (Team VishwaSena). Eight-agent pipeline on NVIDIA NIM, Z-score outlier detection, SOFA/NEWS2 scoring, RAG over clinical guidelines.
- **[Safety Zone Agentic Assistant](https://github.com/sarvadnya2030/safety-zone-agentic-assistant)**: hybrid RAG (BM25 + FAISS + reciprocal rank fusion) with a tool-using LLM agent for Indian disaster-zone questions. Risk scores are computed deterministically; the LLM only explains them.
- **[AI Compiler Optimizer](https://github.com/sarvadnya2030/AI-Compiler-Optimizer)**: an LLM proposes optimized versions of a small C subset, and a Z3 verifier accepts only candidates it proves equivalent. The LLM is never trusted for correctness.
- **[SLM Reasoning Research](https://github.com/sarvadnya2030/Rsearch_Experiments_SLM)**: hypothesis-driven experiments on which reasoning supervision helps a 0.6B model. Baseline: 52.16% on the full GSM8K test set (1,319 problems).
- **[VisAgent](https://github.com/sarvadnya2030/VisAgent)**: Telegram bot that commits files and photos sent to it into a GitHub repo.
- **[DAA-cp](https://github.com/sarvadnya2030/DAA-cp)**: graph algorithms and multi-hop QA experiments on 2WikiMultihop and MuSiQue.
