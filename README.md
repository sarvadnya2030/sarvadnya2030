### 🚀 Projects

| Project | What it does |
|---|---|
| [**ClearFlow**](https://github.com/sarvadnya2030/Clearflow) | ISO 20022 payment orchestration in Java 21, Spring Boot 3.3, Kafka and Camel, with an MCP observability layer. 41 tests. |
| [**HC01**](https://github.com/sarvadnya2030/ignisia-mitwpu-hackathon) | ICU clinical decision support from Ignisia 2026 (Team VishwaSena). Eight-agent pipeline on NVIDIA NIM, Z-score outlier detection, SOFA/NEWS2 scoring, guideline RAG. |
| [**Safety Zone Agentic Assistant**](https://github.com/sarvadnya2030/safety-zone-agentic-assistant) | Hybrid RAG (BM25 + FAISS + reciprocal rank fusion) and a tool-using LLM agent for Indian disaster-zone questions. Risk scores are deterministic; the LLM only explains them. |
| [**AI Compiler Optimizer**](https://github.com/sarvadnya2030/AI-Compiler-Optimizer) | An LLM proposes optimizations for a small C subset. A Z3 verifier accepts only what it proves equivalent. The LLM is never trusted for correctness. |
| [**SLM Reasoning Research**](https://github.com/sarvadnya2030/Rsearch_Experiments_SLM) | Hypothesis-driven experiments on which reasoning supervision helps a 0.6B model. Baseline: 52.16% on the full GSM8K test set (1,319 problems). |
| [**VisAgent**](https://github.com/sarvadnya2030/VisAgent) | Telegram bot: send it a file or photo, it commits it to a GitHub repo. |
| [**DAA-cp**](https://github.com/sarvadnya2030/DAA-cp) | Graph algorithms and multi-hop QA experiments on 2WikiMultihop and MuSiQue. |
